Operator 01

SCAN Document extraction

Built for the paperwork that never arrives in one piece — pedimentos, commercial invoices, packing lists and certificates of origin, spread across threads and senders. SCAN reads every page, decides what each document actually is, pulls the fields out and groups them back into the operation they belong to.

See SCAN

The manual process today

  • Open every PDF and key the fields by hand
  • Cross-check the pedimento against each invoice, line by line
  • Rebuild the operation from attachments in several emails
  • Type the same data again into the client’s system
  • Total time: hours per operation

With InTake

  • Reads every page and classifies each document on its own
  • Extracts the four document types in parallel
  • Groups the documents back into their operation
  • Keeps what doesn’t fit the schema instead of dropping it
  • Total time: under 30 seconds
Operator 02

AUDIT Compliance review

The review that protects you from a fine is the one nobody has time to finish. AUDIT runs sixteen numbered checks over every operation — dates, values, tariff codes, permits, quotas, permanence — and returns each finding with the article it comes from and what it could cost in pesos.

See AUDIT

The manual process today

  • Check the pedimento against the Ley Aduanera by hand
  • Look up each tariff code in the LIGIE and its annexes
  • Calculate the DTA and contributions in a spreadsheet
  • Verify suppliers against the SAT’s 69-B list
  • And still find out when the fine arrives

With InTake

  • Sixteen numbered validations on every operation
  • Each finding with its article and a range in pesos
  • Suppliers cross-checked against the EFOS catalogue
  • Adapts to the documents you actually have
  • The error shows up before you transmit
Operator 03

SCOUT Tariff classification

Classifying is a judgement call, and a judgement call needs an argument behind it. SCOUT proposes the tariff code with the General Rules it applied written out, how confident it is, and the regulatory dossier already attached — NOMs, permits, quotas and PROSEC.

See SCOUT

The manual process today

  • Hunt for the code leafing through the TIGIE
  • Ask the customs broker and wait for an answer
  • Track down NOMs, permits and quotas separately
  • Decide with no record of why it was decided
  • And find the mistake at the review

With InTake

  • Proposes the code with the General Rules it applied
  • Brings the regulatory dossier attached
  • States its confidence on every proposal
  • Flags the gap when it can’t decide
  • The reasoning stays on the record
